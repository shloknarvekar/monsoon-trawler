# Monsoon Trawler

Fishing boat game in C++ set on the Goa coast. Made for my OOP course.

Pick a boat (sail, motor or hybrid), go fishing at Aguada, deep sea or Grande Island, and sell your catch at Panjim market. Try to make Rs 1,00,000 before December. You cant fish in June and July because of the monsoon ban.

## Run

```
g++ monsoon_trawler.cpp -o monsoon_trawler
./monsoon_trawler
```

The game makes a `logbook.txt` and `trawler_save.txt` in the same folder.
